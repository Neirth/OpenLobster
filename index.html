What changed

Every OpenClaw flaw, fixed.

OpenClaw had a moment. Then the security community looked at it. OpenLobster is what you get when you take that feedback seriously.

🔒

Security by default

Dashboard auth is on by default — not opt-in. Config and secrets are encrypted on disk. API keys live in a secrets backend (encrypted file or OpenBao), not in plain YAML. No leaked OPENLOBSTER_* env vars to terminal tools.

🧠

Real memory system

MEMORY.md is not a memory system — it's a wiki. OpenLobster uses a proper Neo4j graph database with typed nodes, edges, and relationships. Browse and edit it live from the UI. File backend available for local setups.

👥

True multi-user support

Each user on every channel is a first-class entity with their own conversation history, tool permissions, and pairing flow. A Telegram user and a Discord user can talk to the same agent without stepping on each other.

⏰

Proper task scheduler

The 30-minute heartbeat loop reading HEARTBEAT.md is gone. Real cron expressions for recurring jobs, ISO 8601 for one-shot tasks. Status, next-run times, and logs visible in the dashboard.

🔌

Full MCP integration

Connects to any Streamable HTTP MCP server, handles full OAuth 2.1, lets you browse tools per server, and gives you a per-user permission matrix. One-click marketplace for integrations.

⚡

Go backend, single binary

Rewrote the Node.js backend in Go. 200ms startup vs 2-3s. 30 MB RAM vs 150 MB+. Single static binary — no npm, no Node version pinning, no node_modules. Runs on a Raspberry Pi 3 or a $15 LicheeRV Nano.

Quick start

Up in under a minute.

Single binary, no runtime dependencies. Works on Linux, macOS, and anything that runs Go — including ARM boards.

build & run 
# Install deps & build
pnpm install
pnpm build --filter=@openlobster/backend

# Run — dashboard at :8080
./dist/openlobster
docker 
docker run -p 8080:8080 \
  -e OPENLOBSTER_GRAPHQL_HOST=0.0.0.0 \
  -e OPENLOBSTER_GRAPHQL_AUTH_TOKEN=secret \
  -v ~/.openlobster/data:/app/data \
  ghcr.io/neirth/openlobster/openlobster:latest
minimal env config 
# Agent
OPENLOBSTER_AGENT_NAME=my-agent

# Database
OPENLOBSTER_DATABASE_DRIVER=sqlite
OPENLOBSTER_DATABASE_DSN=./data/openlobster.db

# Auth (set this before going public!)
OPENLOBSTER_GRAPHQL_AUTH_TOKEN=your-secret

# AI provider — pick one
OPENLOBSTER_PROVIDERS_OLLAMA_ENDPOINT=http://localhost:11434
OPENLOBSTER_PROVIDERS_ANTHROPIC_API_KEY=sk-ant-…
OPENLOBSTER_PROVIDERS_OPENAI_API_KEY=sk-…
